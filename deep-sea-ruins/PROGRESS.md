# DEEP-SEA 3Dモデル制作の進行記録

別のゲームのリポジトリ (『甲殻類にも都合があります。』の `crustaceans-have-plans`、Codex が作業中) と**作業がぶつからないよう**、今後使える3Dモデルはこの NEXUS に作って記録します。ゲーム側に取り込むときは `data/assets.json` の `rawUrl` (コミット固定を推奨) から読みます。

## 方針

- 外部のコード・モデル・画像は使わない。参考にした公開リポジトリは、ライセンスを確認して各コレクションの README に書く (ライセンス未記載のものは見るだけにとどめる)。
- 形はオリジナル。1 unit = 1 m、Y が上、原点は足元 (底面の中心)、正面は +Z。軽く (1点 数千三角形以下)、テクスチャは極力使わない。
- 1コレクションごとに、生成スクリプト (`scripts/<名前>/`)、README、サムネイル、`data/assets.json` の記録、この進行記録を残す。作ったらコミットして GitHub に記録する。

- 内訳: 船殻 4 (耐圧 Mk1/Mk2/Mk3・殻の補強) / 推進・浮力・電源 4 (小型スラスター・大型エンジン・バラストタンク・バッテリー) / 探知 2 (ソナーの皿・ハイドロフォン列) / 照明 2 (前照灯・投光灯バー) / 作業・貨物 4 (作業アーム・テザーのウインチ・貨物ポッド・標本ラック) / 乗員・通信・補修 4 (ハッチ塔・ドームの窓・アンテナマスト・修理キット)。
- 232〜2,536 三角形、合計約 1.3 MB、テクスチャなし。`glass` だけが alpha blend (GLB 側も alphaMode BLEND と確認)。

- 確認で直したこと: サムネイルにデフォルトの立方体が写っていた → レンダーから除外。スラスターの筒が閉じていて羽が見えなかった → 環 (ダクト) と羽が見える形に作り直した。ハッチ塔の高さの説明を実測に合わせた。

- 注意: 新しい GLB を置いたあと、`npm run scan` を先に走らせると記録が簡易版で重複するので、必ず `npm run deep-sea-submarine` を先に実行する。
