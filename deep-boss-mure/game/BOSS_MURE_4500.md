# 4,500m「誰もいない王（ムレ）」検証用の仮実装

2026-11-05。ユーザー指示「ボスの造形・戦闘を含めて仮実装」。**HP・ダメージ・時間・射程はすべて仮の値で、仕様ではない。** 仕様文書 (GAME_SPEC など) は変更していない。

## 入口
`/boss-debug.html` の一覧の 4,500m「誰もいない王（ムレ）」→ `/boss-mure.html`。バド・アクセル・ハンスの3人。通常探索・保存データには触れない（専用アリーナ）。

## 見た目
約4万匹の小魚だけで姿をつくる (NEXUS `deep-boss-mure`)。`assets/models/boss_mure_school.bin` (float32 x 11 / 匹) を InstancedBufferGeometry で描く (頂点シェーダーで揺れ・翼の羽ばたき・尾のうねり・脱皮・被弾の散りを計算)。`boss_mure.glb` は形の確認用 (ビューアー用)。肉体は無く、中心は空洞。

## 仮の戦闘 (`src/bossDebug/mureFight.ts`、Three.js・DOM非依存)
16秒の周期: 漂泳 2.5s → 魚群が翼へ集まる (予兆、狙いは6.5sで固定) → 奔流 1.4s (翼から魚の帯が走る。同じ線分で判定、ダメージ2、1周期に1回) → 脱皮 (魚が輪郭から離れて戻る。隙あり、攻撃+1)。奔流は周期ごとに左右の翼が交互。
ボスHP 70、プレイヤーHP 8 (3人共有)。近接5.5m・アクセルの射撃58m。攻撃は最も近い発光マーカー (頭・王冠・胸・両翼の先) へ。光の糸は200m、高さ上限130m。回避中と被弾後は無敵。

## 検証
`npm run build`、`node --experimental-strip-types tools/check_mure_boss.mjs` (配置データの大きさ、糸・高さ、狙い固定、奔流の命中・回避・1周期1回、脱皮ボーナス、勝敗・リセット)、`tools/check_boss_debug.mjs` (6体に更新)。ブラウザーで描画・フェーズの一巡・奔流の帯・射撃でのHP減少・一覧の表示を確認。
未確認: 実機パッドの手触り、難易度、性能 (4万匹は手元のブラウザーで動いたが低スペックPCは未確認)、脱皮の見せ方の好み、乳白色の海の質感 (背景は仮の床と柱)。
